# geological-disaster-ledger-data-processing
鄂西北地质灾害隐患台账ETL治理与业务管理项目，基于PostgreSQL+PostGIS空间数据库完成GPS坐标规整清洗、重复灾害点位去重、矢量空间关联行政区划分、灾害风险等级多维度聚合统计；
基于SpringBoot开发台账管理后端接口，使用EasyExcel实现隐患台账批量导入导出，搭配QGIS完成空间图层可视化渲染，完整覆盖空间数据ETL治理、后端业务开发、GIS可视化落地全流程。
> 说明：本仓库仅存放业务代码与项目文档，涉密原始业务数据库、全量隐患点位原始数据不纳入版本控制，保障业务数据安全。
